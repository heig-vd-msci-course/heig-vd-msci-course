# Présentations du vendredi 23 octobre 2026

## Sur l'ordinateur de présentation (Windows)

1. Sur GitHub, ouvrir la branche de ce dossier, puis **Code > Download ZIP**
2. Extraire le ZIP (clic droit > Extraire tout), puis ouvrir le dossier `03 - Evaluations`
3. Choisir une façon de lancer :
   - **`index.html`** (recommandé) : page de pilotage, une ligne par équipe dans l'ordre
     de passage, avec un bouton pour la présentation et un pour le projet
   - **`ouvrir-tout.bat`** : ouvre d'un coup toutes les présentations et tous les projets,
     dans l'ordre de passage
   - **`ouvrir.bat`** dans le dossier d'une équipe : ouvre sa présentation et son projet

Si Windows affiche « Windows a protégé votre ordinateur » pour un `.bat`, cliquer sur
**Informations complémentaires > Exécuter quand même**.

Le dossier `code/` d'une équipe contient une copie de son projet MDN Playground :
ouvrir `code/index.html` si le lien en ligne ne fonctionne pas.

Le récapitulatif des rendus se trouve dans `BILAN.md`.
