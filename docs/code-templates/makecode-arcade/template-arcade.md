# Templates MakeCode Arcade - Jeu des Allumettes

Templates pour l'activité MakeCode Arcade du lundi après-midi.

## Approche pédagogique

**100% blocs visuels** : les élèves construisent le jeu uniquement par drag and drop, sans jamais toucher au code TypeScript/JavaScript.

## Fichiers

| Fichier | Description | Pour qui |
|---------|-------------|----------|
| `jeu-allumettes-compact-instructions.md` | Guide pas à pas avec blocs | Élèves |
| `jeu-allumettes-compact-solution.ts` | Version complète (référence) | Enseignante uniquement |

## Contrôles du jeu

| Touche | Action |
|--------|--------|
| A (Z) | Retirer 1 allumette |
| B (X) | Retirer 2 allumettes |
| ↑ | Retirer 3 allumettes |

## Concepts abordés (via les blocs)

- **Variables** : créer et modifier des variables
- **Conditions** : blocs `si ... alors`
- **Opérateurs** : comparaisons, calculs, modulo
- **Événements** : blocs `quand bouton ... pressé`
- **Duplication** : copier des blocs pour les réutiliser

## Progression

1. **Version simple** : l'ordinateur retire toujours 1 allumette
2. **Version avancée** : stratégie gagnante avec le modulo
