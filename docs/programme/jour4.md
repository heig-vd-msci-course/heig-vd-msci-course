# Jour 4 - Jeudi

## Travail libre à domicile

> *Consolidation des acquis et préparation du projet final.*

---

!!! info "Journée de travail autonome"

    Le jeudi est consacré au travail individuel à domicile. Cette journée permet de consolider les apprentissages de la semaine et de préparer le projet final.

---

## Objectifs du jour

Cette journée permet de :

1. **Consolider** les concepts appris (HTML, CSS, JavaScript, micro:bit)
2. **Approfondir** les éléments selon les intérêts personnels
3. **Préparer** le projet créatif du vendredi

---

## Suggestions d'activités

### Révision des concepts

- Relire les fiches de référence (cheat sheets)
- Revoir les projets réalisés en classe
- Identifier les points à clarifier

### Approfondissement

- Explorer les tutoriels supplémentaires sur MakeCode
- Expérimenter avec JSFiddle
- Consulter les ressources en ligne recommandées

### Préparation du projet

- Réfléchir à une idée de projet personnel
- Esquisser l'interface ou le fonctionnement souhaité
- Lister les fonctionnalités à implémenter

---

## Préparation du vendredi

Pour arriver avec une bonne préparation le vendredi :

- [ ] Choisir un type de projet (jeu, site web, objet interactif)
- [ ] Définir 2-3 fonctionnalités principales
- [ ] Préparer des questions pour l'équipe enseignante

!!! note "Projet final"

    Le vendredi est consacré à la réalisation d'un projet créatif personnel. Arriver avec une idée, même simple, permet de maximiser le temps de création.

---

## En cas de difficulté

Si des questions surgissent pendant cette journée de travail autonome :

- Noter les points de blocage pour les aborder vendredi
- Consulter les fiches de référence du site
- Rechercher des exemples similaires sur les plateformes utilisées
