# Jour 5 - Vendredi

## Projet créatif et clôture

> *Réalisation d'un projet personnel et présentation des travaux.*

---

!!! warning "Page en construction"

    Le contenu détaillé de cette journée est en cours de préparation.

---

## Objectifs du jour

À l'issue de cette journée, il sera possible de :

1. **Concevoir** un projet créatif combinant les apprentissages de la semaine
2. **Réaliser** une création fonctionnelle (jeu, site, objet interactif)
3. **Présenter** oralement son travail devant le groupe

---

## Aperçu du programme

### Matin : Réalisation du projet

- Présentation des options de projets
- Choix et planification individuelle
- Atelier de création accompagnée
- Points d'avancement collectifs

### Après-midi : Finalisation et présentations

- Finalisation des projets
- Préparation des présentations
- Présentations orales (2-3 minutes par projet)
- Remise des certificats et clôture

---

## Options de projets

Plusieurs directions possibles selon les intérêts :

| Type | Description | Technologies |
|------|-------------|--------------|
| **Jeu web** | Jeu interactif dans le navigateur | HTML, CSS, JavaScript |
| **Site personnel** | Portfolio ou page de présentation | HTML, CSS |
| **Objet interactif** | Création avec micro:bit | MakeCode micro:bit |
| **Jeu MakeCode** | Jeu 2D en programmation visuelle | MakeCode Arcade |

---

## Lien avec le fil rouge

Le jeu des allumettes peut être finalisé et personnalisé :

- Intégration de toutes les versions (web, micro:bit)
- Personnalisation graphique et sonore
- Ajout de fonctionnalités créatives

---

## Critères de présentation

Chaque présentation inclut :

- **Démonstration** : montrer le projet en fonctionnement
- **Explications** : décrire les choix techniques
- **Difficultés** : partager les obstacles rencontrés et solutions trouvées
- **Perspectives** : évoquer les améliorations possibles
