# Mardi

## HTML, CSS et publication web

> *Création d'un site web personnel et découverte des langages du web.*

!!! info "Rendez-vous"

    **08h30** · Salle **R102**

---

## Objectifs du jour

À l'issue de cette journée, il sera possible de :

1. **Structurer** une page web avec HTML, la **styliser** avec CSS et la **mettre en page** avec Flexbox et Grid
2. **Utiliser** en JavaScript les concepts découverts lundi en blocs : variables, événements, conditions et boucles
3. **Lire** les messages d'erreur et corriger un bug, en HTML, en CSS et en JavaScript
4. **Créer** en équipe l'interface web du jeu des allumettes

## Lien avec le fil rouge

Le jeu des allumettes prend forme sur le web :

- Les concepts du lundi (variables, événements, conditions, boucles) sont repris un par un, en JavaScript, avec leur équivalent MakeCode
- L'interface du jeu est créée en HTML, stylisée avec CSS (allumettes dessinées, boutons) et animée avec JavaScript
- Mercredi, le même jeu prendra une forme physique avec le micro:bit
