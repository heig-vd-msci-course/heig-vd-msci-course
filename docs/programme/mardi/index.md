# Mardi

## HTML, CSS et publication web

> *Création d'un site web personnel et découverte des langages du web.*

!!! info "Rendez-vous"

    **08h30** · Salle **R102**

---

!!! warning "Page en construction"

    Le contenu détaillé de cette journée est en cours de préparation.

---

## Objectifs du jour

À l'issue de cette journée, il sera possible de :

1. **Structurer** une page web avec HTML
2. **Styliser** du contenu avec CSS
3. **Publier** un site web en ligne

---

## Aperçu du programme

### Matin : HTML et CSS

- Introduction au web et fonctionnement des navigateurs
- Structure d'une page HTML : balises, attributs, hiérarchie
- Mise en forme avec CSS : couleurs, polices, espacements
- Tutoriel pas à pas : création et personnalisation d'une page personnelle

### Après-midi : JavaScript et publication

- Introduction à JavaScript : variables, événements, conditions et boucles
- Atelier : l'interface web du jeu des allumettes, en équipe
- Rendre son projet (avant 16h30)
- Synthèse et quiz Wooclap

---

## Thèmes abordés

| Concept | Description |
|---------|-------------|
| **HTML** | Langage de structuration du contenu web |
| **CSS** | Langage de mise en forme visuelle |
| **JavaScript** | Langage de programmation pour l'interactivité |
| **Hébergement** | Publication d'un site accessible en ligne |

---

## Lien avec le fil rouge

Le jeu des allumettes prend forme sur le web :

- Création de l'interface utilisateur en HTML
- Stylisation avec CSS (allumettes visuelles, boutons)
- Logique du jeu en JavaScript

---

## À rendre en fin de journée

!!! warning "Projet à envoyer avant mardi 16h30"

    En fin de journée, chaque équipe envoie son projet web (l'interface du jeu des allumettes) par e-mail à l'équipe enseignante, qui le publie en ligne dans la soirée. Les instructions détaillées sont données à la fin de l'après-midi : [Rendre son projet](apres-midi.md#rendre-son-projet){target="_blank"}.
