## L'IA dans votre quotidien

L'intelligence artificielle est présente dans de nombreuses applications utilisées au quotidien, souvent sans qu'on s'en rende compte.

### Exemples concrets

| Application | Ce que fait l'IA |
|-------------|------------------|
| **TikTok** | Sélectionne les vidéos du flux "Pour Toi" |
| **Spotify** | Crée des playlists personnalisées (Discover Weekly) |
| **Snapchat** | Applique les filtres sur le visage en temps réel |
| **Instagram** | Suggère les Reels et les comptes à suivre |
| **BeReal** | Propose des réactions adaptées |

### Deux types d'IA

| IA de recommandation | IA générative |
|---------------------|---------------|
| Choisit parmi du contenu existant | Crée du nouveau contenu |
| TikTok, Spotify, Netflix | ChatGPT, Claude, Midjourney |
| "Voici ce que tu pourrais aimer" | "Voici ce que j'ai créé pour toi" |

### Comment fonctionne l'IA générative ?

L'IA générative fonctionne sur le principe de l'**autocomplétion avancée** :

1. **Entraînement** : l'IA analyse des milliards de textes
2. **Apprentissage** : elle identifie des patterns statistiques
3. **Génération** : elle prédit le mot suivant le plus probable

!!! info "Analogie"

    Quand on écrit un message sur téléphone, le clavier suggère le mot suivant. L'IA générative fait la même chose, mais à une échelle immense et avec une grande cohérence.

### Ce que l'IA fait bien

| Tâche | Pourquoi ça fonctionne |
|-------|------------------------|
| **Générer des idées** | Combine des patterns de manière créative |
| **Rédiger des brouillons** | Structure bien le texte |
| **Expliquer des concepts** | Reformule de différentes manières |
| **Traduire** | Connaît de nombreuses langues |
| **Résumer** | Identifie les points clés |

### Ce que l'IA fait moins bien

| Tâche | Pourquoi c'est difficile |
|-------|--------------------------|
| **Faits et citations** | Peut inventer des sources inexistantes |
| **Calculs mathématiques** | Prédit les mots, ne calcule pas vraiment |
| **Actualités récentes** | Entraînée sur des données passées |
| **Comprendre le contexte réel** | N'a pas d'expérience du monde physique |

### Les hallucinations

Les **hallucinations** sont des erreurs où l'IA génère des informations fausses avec confiance, comme si elles étaient vraies.

!!! warning "Exemple d'hallucination"

    > "Le pont de Lausanne a été construit en 1847 par l'architecte Jean-Pierre Moreau."

    Ce pont n'existe pas. Cet architecte non plus. Mais la phrase "sonne" correcte.

L'IA ne sait pas qu'elle se trompe car elle n'a pas de compréhension du monde réel — elle génère simplement du texte statistiquement probable.

## Règles d'usage de l'IA

Ces règles correspondent aux **pratiques professionnelles** appliquées dans les entreprises technologiques. Elles ne sont pas là pour restreindre, mais pour garantir une utilisation efficace et responsable.

### Règle 1 : Pas de copier-coller aveugle

Toujours comprendre ce qu'on utilise avant de l'intégrer.

| À faire | À éviter |
|---------|----------|
| Relire le code ou le texte généré | Copier directement sans lire |
| Vérifier que ça correspond au besoin | Accepter la première réponse |
| Tester et valider le résultat | Soumettre sans vérification |

**Question test** : "Est-ce que je peux expliquer chaque ligne à quelqu'un d'autre ?"

### Règle 2 : Comprendre avant d'utiliser

L'IA est un assistant, pas un remplaçant.

| Bonne utilisation | Mauvaise utilisation |
|------------------|---------------------|
| Demander des explications | Copier sans comprendre |
| Comparer avec ses propres idées | Faire confiance aveuglément |
| Poser des questions de suivi | Ignorer les erreurs possibles |

### Règle 3 : Citer et documenter

La transparence est obligatoire. Quand l'IA est utilisée, il faut indiquer :

- **Quel outil** : Claude, ChatGPT, Copilot, Gemini...
- **Pour quoi** : brainstorming, code, relecture, traduction...
- **Comment** : le type de prompt utilisé, les modifications apportées

!!! example "Exemple de citation"

    "Code initial généré avec Claude, modifié pour ajouter la gestion des erreurs."

### Pourquoi ces règles ?

1. **Éviter la dépendance** : rester capable de travailler sans IA
2. **Garantir la compréhension** : savoir ce qu'on fait et pourquoi
3. **Être honnête** : la transparence est une valeur professionnelle

## Atelier : Générer du code avec une IA

### Objectif

Observer ce que l'IA génère, tester si ça fonctionne, identifier les limites, et comprendre pourquoi savoir coder reste essentiel.

### Outils disponibles

| Outil | Accès |
|-------|-------|
| **Claude** | [claude.ai](https://claude.ai){target="_blank"} |
| **ChatGPT** | [chatgpt.com](https://chatgpt.com){target="_blank"} |
| **Gemini** | [gemini.google.com](https://gemini.google.com){target="_blank"} |

Utiliser un compte personnel ou créer un compte gratuit.

### Les trois défis

Tester l'IA sur les technologies découvertes cette semaine :

| Défi | Technologie | Lien avec le cours |
|------|-------------|-------------------|
| **1** | MakeCode Arcade | Lundi après-midi |
| **2** | Site web (HTML/CSS/JS) | Mardi |
| **3** | micro:bit (MakeCode) | Ce matin |

### Défi 1 : MakeCode Arcade

**Exemple de prompt :**

> Crée un jeu MakeCode Arcade où un personnage doit attraper des objets qui tombent du haut de l'écran.

**Questions à se poser :**

- Le code généré correspond-il à la demande ?
- Peut-il être importé dans MakeCode ?
- Fonctionne-t-il correctement ?
- Comment l'améliorer ?

### Défi 2 : Site web

**Exemple de prompt :**

> Crée une page HTML avec un titre, une image, et un bouton qui change la couleur de fond quand on clique dessus.

**Questions à se poser :**

- Le HTML est-il valide ?
- Le CSS est-il bien appliqué ?
- Le JavaScript fonctionne-t-il ?
- Le code est-il compréhensible ?

### Défi 3 : micro:bit

**Exemple de prompt :**

> Crée un programme micro:bit qui affiche un smiley quand on appuie sur le bouton A et un cœur quand on appuie sur le bouton B.

**Questions à se poser :**

- Le code peut-il être importé dans MakeCode pour micro:bit ?
- Les blocs correspondent-ils à ceux découverts ce matin ?
- Y a-t-il des erreurs ou des incompatibilités ?

### Observations à partager

Après l'atelier, discussion collective :

- L'IA a-t-elle réussi les défis ?
- Quelles erreurs ont été trouvées ?
- Le code a-t-il dû être corrigé ou adapté ?
- Le code généré était-il compréhensible ?

### La leçon

| Sans connaissances en programmation | Avec connaissances en programmation |
|-------------------------------------|-------------------------------------|
| Impossible de savoir si c'est correct | Capacité à vérifier et valider |
| Impossible de corriger les erreurs | Capacité à améliorer |
| Dépendance totale | Contrôle et autonomie |

!!! success "Message clé"

    Plus on comprend la programmation, plus l'IA devient un outil utile. Moins on comprend, plus on devient dépendant.

## Définition du mini-projet

### Le projet créatif de vendredi

Vendredi, chaque équipe présente un projet réalisé avec **une** des trois technologies de la semaine : MakeCode Arcade, HTML/CSS/JavaScript ou micro:bit. Deux options sont possibles :

- **Option A** : améliorer le jeu des allumettes, avec une amélioration par membre de l'équipe
