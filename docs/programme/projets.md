## Parcourir le code

Le lien **Code** affiche le HTML, le CSS et le JavaScript d'un projet avec coloration
syntaxique. Le bouton **Ouvrir dans JSFiddle** de cette page permet de modifier le code
et de voir le résultat directement dans le navigateur, sans compte.

Les projets réalisés avec MakeCode (Arcade ou micro:bit) s'ouvrent directement dans
l'éditeur MakeCode, qui affiche les blocs.
