# Où se cache l'IA ?

## Dans votre téléphone, tous les jours

| Application | Ce que fait l'IA |
|-------------|------------------|
| **TikTok** | Choisit les vidéos "Pour Toi" |
| **Spotify** | Crée vos playlists personnalisées |
| **Snapchat** | Applique les filtres sur votre visage |
| **Instagram** | Suggère les Reels et les comptes |
| **BeReal** | Propose des réactions adaptées |

---

# L'algorithme TikTok

## Comment il vous connaît si bien ?

1. **Observe** : temps passé, likes, partages, commentaires
2. **Analyse** : patterns dans vos préférences
3. **Prédit** : ce qui va vous plaire ensuite
4. **Teste** : propose du nouveau contenu
5. **Affine** : ajuste selon vos réactions

*Plus vous scrollez, plus il vous "comprend".*

---

# Spotify Discover Weekly

## 30 chansons chaque lundi

L'IA analyse :

- Les artistes que vous écoutez
- Les playlists que vous suivez
- Les morceaux que les personnes avec des goûts similaires écoutent
- Le tempo, le genre, l'énergie des morceaux

Résultat : une playlist personnalisée juste pour vous.

---

# Les filtres Snapchat et Instagram

## Comment ça marche ?

1. **Détection du visage** : 68 points de repère
2. **Suivi en temps réel** : 30 fois par seconde
3. **Application du filtre** : superposition 3D

Tout ça en quelques millisecondes sur votre téléphone.

# L'IA générative

## Différente de l'IA de recommandation

| IA de recommandation | IA générative |
|---------------------|---------------|
| Choisit parmi du contenu existant | Crée du nouveau contenu |
| TikTok, Spotify, Netflix | ChatGPT, Claude, Midjourney |
| "Voici ce que tu pourrais aimer" | "Voici ce que j'ai créé pour toi" |

---

# Comment fonctionne l'IA générative ?

## L'analogie de l'autocomplétion

Quand on écrit un message, le téléphone suggère le mot suivant.

**L'IA générative fait pareil, mais à très grande échelle.**

1. Entraînée sur des milliards de textes
2. Apprend des patterns statistiques
3. Prédit le mot le plus probable ensuite

---

# Ce que l'IA fait bien

| Tâche | Pourquoi |
|-------|----------|
| **Générer des idées** | Combine des patterns de manière créative |
| **Rédiger des brouillons** | Structure bien le texte |
| **Expliquer des concepts** | Reformule de différentes manières |
| **Traduire** | Connaît beaucoup de langues |
| **Résumer** | Identifie les points clés |

---

# Ce que l'IA fait moins bien

| Tâche | Pourquoi |
|-------|----------|
| **Faits et citations** | Peut inventer des sources |
| **Calculs mathématiques** | Prédit les mots, ne calcule pas vraiment |
| **Actualités récentes** | Entraînée sur des données passées |
| **Comprendre le contexte** | N'a pas d'expérience du monde réel |

---

# Les hallucinations

## Quand l'IA invente avec confiance

L'IA génère du texte qui "sonne" bien, même s'il est faux.

**Exemple :**
> Le pont de Lausanne a été construit en 1847 par l'architecte Jean-Pierre Moreau.

*Ce pont n'existe pas. Cet architecte non plus.*

L'IA ne sait pas qu'elle se trompe.

# Règles d'usage de l'IA

## 14h40 - 15h00

---

# Pourquoi des règles ?

## Ce n'est pas pour vous punir

Ces règles correspondent aux **pratiques professionnelles** en entreprise.

- Les développeurs utilisent l'IA quotidiennement
- Mais avec des règles strictes
- Pour rester compétents et responsables

---

# Règle 1 : Pas de copier-coller aveugle

## Toujours comprendre ce qu'on utilise

- Relire le code ou le texte généré
- Vérifier qu'il fait ce qu'on veut
- Ne jamais soumettre quelque chose qu'on ne comprend pas

**Question test :** Pouvez-vous expliquer chaque ligne à quelqu'un d'autre ?

---

# Règle 2 : Comprendre avant d'utiliser

## L'IA est un assistant, pas un remplaçant

| Bonne utilisation | Mauvaise utilisation |
|------------------|---------------------|
| Demander des explications | Copier sans lire |
| Comparer avec ses propres idées | Accepter la première réponse |
| Poser des questions de suivi | Faire confiance aveuglément |

---

# Règle 3 : Citer et documenter

## La transparence est obligatoire

Quand l'IA est utilisée, il faut indiquer :

- **Quel outil** : Claude, ChatGPT, Copilot...
- **Pour quoi** : brainstorming, code, relecture...
- **Comment** : le prompt utilisé, les modifications apportées

*C'est ce qu'on attend dans le monde professionnel.*

---

# Pourquoi ces règles ?

## Trois raisons principales

1. **Éviter la dépendance** : rester capable de travailler sans IA
2. **Garantir la compréhension** : savoir ce qu'on fait
3. **Être honnête** : la transparence est une valeur professionnelle

---

# Le message clé

## L'IA est un outil puissant

Comme tout outil puissant, il faut apprendre à l'utiliser correctement.

Un marteau peut construire une maison ou casser un orteil.
L'IA peut accélérer l'apprentissage ou l'empêcher.

**C'est vous qui décidez.**

# Défi 1 : MakeCode Arcade

## Demander à l'IA de créer un jeu simple

**Exemple de prompt :**

> Crée un jeu MakeCode Arcade où un personnage doit attraper des objets qui tombent.

**Questions à se poser :**
- Le code généré fonctionne-t-il ?
- Correspond-il à la demande ?
- Comment l'améliorer ?

---

# Défi 2 : Site web

## Demander à l'IA de créer une page HTML/CSS

**Exemple de prompt :**

> Crée une page web avec un titre, une image et un bouton qui change la couleur de fond.

**Questions à se poser :**
- Le HTML est-il valide ?
- Le CSS est-il bien appliqué ?
- Le JavaScript fonctionne-t-il ?

---

# Défi 3 : micro:bit

## Demander à l'IA de créer un programme

**Exemple de prompt :**

> Crée un programme micro:bit qui affiche un smiley quand on appuie sur le bouton A et un cœur quand on appuie sur le bouton B.

**Questions à se poser :**
- Le code peut-il être importé dans MakeCode ?
- Les blocs correspondent-ils à ceux qu'on connaît ?
- Y a-t-il des erreurs ?

---

# Observations à partager

## Après l'atelier

- L'IA a-t-elle réussi les défis ?
- Quelles erreurs avez-vous trouvées ?
- Avez-vous dû corriger ou adapter le code ?
- Comprenez-vous ce que fait le code généré ?

---

# La leçon de cet atelier

## Savoir coder = mieux utiliser l'IA

| Sans connaissances | Avec connaissances |
|-------------------|-------------------|
| On ne sait pas si c'est bon | On peut vérifier |
| On ne peut pas corriger | On peut améliorer |
| On est dépendant | On reste en contrôle |

*Plus on comprend, plus l'IA devient utile.*
