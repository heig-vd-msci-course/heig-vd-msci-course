# Prise de température - Lundi Matin

## Objectif

Ce sondage Mentimeter permet de :
- Accueillir les étudiantes et créer un premier moment de participation
- Évaluer l'humeur générale du groupe
- Identifier les représentations autour de la programmation
- Recueillir les attentes et les craintes pour adapter le cours

## Quand l'utiliser

- **Moment** : Période 1, après l'accueil et les présentations (environ 10 minutes après le début)
- **Durée totale** : 10-15 minutes (sondage + debrief)
- **Affichage** : Projeter les résultats en temps réel pour créer de l'engagement

## Slide 1 : Humeur du matin

### Configuration Mentimeter

| Paramètre | Valeur |
|-----------|--------|
| **Type de slide** | Scales (échelle) |
| **Affichage** | Emoji scale ou échelle 1-5 |

### Question

> **Comment tu te sens ce matin ?**

### Échelle proposée

| Valeur | Emoji | Signification |
|--------|-------|---------------|
| 1 | 😴 | Encore endormie |
| 2 | 😐 | Moyen |
| 3 | 🙂 | Ça va |
| 4 | 😊 | Bien |
| 5 | 🤩 | Super motivée |

### Paramètres recommandés

- Afficher les résultats en temps réel : Oui
- Permettre plusieurs réponses : Non
- Afficher la moyenne : Oui

### Notes de facilitation

- Commencer par répondre toi-même pour montrer l'exemple
- Rassurer : il n'y a pas de bonne ou mauvaise réponse
- Commenter brièvement les résultats : "Je vois qu'on a un groupe plutôt [état], c'est normal un lundi matin !"

## Slide 2 : Nuage de mots "Programmation"

### Configuration Mentimeter

| Paramètre | Valeur |
|-----------|--------|
| **Type de slide** | Word Cloud (nuage de mots) |
| **Entrées par personne** | 1 à 3 mots |

### Question

> **Quand tu entends "programmation", tu penses à quoi ?**

### Sous-titre (optionnel)

> Entre 1 à 3 mots qui te viennent spontanément

### Paramètres recommandés

- Nombre d'entrées par personne : 3
- Profanity filter : Activé
- Afficher en temps réel : Oui
- Couleurs : Palette colorée pour plus de dynamisme

### Notes de facilitation

- Laisser 1-2 minutes pour que tout le monde réponde
- Observer les mots qui apparaissent : certains seront positifs (créativité, jeux), d'autres négatifs (difficile, maths, geek)
- Utiliser ce nuage comme point de départ pour la discussion : "Intéressant ! Je vois le mot [X] qui revient souvent..."
- Rassurer sur les perceptions négatives : "On va justement déconstruire certaines de ces idées cette semaine"

### Mots attendus (pour préparer le debrief)

**Potentiellement positifs** : jeux vidéo, apps, créativité, robots, IA, sites web

**Potentiellement neutres** : code, ordinateur, logiciel, technique

**Potentiellement négatifs** : difficile, maths, compliqué, geek, ennuyeux, binaire

## Slide 3 : Attentes pour la semaine

### Configuration Mentimeter

| Paramètre | Valeur |
|-----------|--------|
| **Type de slide** | Multiple Choice (choix multiple) |
| **Sélection** | Plusieurs réponses possibles |

### Question

> **Cette semaine, tu espères... (choisis jusqu'à 3 réponses)**

### Options proposées

1. Comprendre comment fonctionne un site web
2. Créer quelque chose de concret à montrer
3. Découvrir si la programmation pourrait me plaire
4. Travailler en équipe sur un projet
5. Apprendre des trucs utiles pour mon futur
6. Passer un bon moment et m'amuser
7. Me dépasser et relever un défi
8. Autre (précise dans le slide suivant)

### Paramètres recommandés

- Nombre maximum de sélections : 3
- Afficher les résultats : En pourcentage et barres
- Afficher en temps réel : Oui

### Notes de facilitation

- Annoncer qu'on peut choisir plusieurs réponses
- Mettre en avant les attentes les plus populaires
- Faire le lien avec le programme : "Bonne nouvelle, on va justement [reprendre l'attente populaire]"

## Slide 4 : Craintes et inquiétudes

### Configuration Mentimeter

| Paramètre | Valeur |
|-----------|--------|
| **Type de slide** | Open Ended (réponse ouverte) |
| **Affichage** | Liste anonyme ou nuage |

### Question

> **Qu'est-ce qui t'inquiète ou te fait un peu peur pour cette semaine ?**

### Sous-titre

> Pas de jugement, sois honnête. Tes réponses sont anonymes.

### Paramètres recommandés

- Réponses anonymes : Oui (important !)
- Longueur max : 100 caractères
- Profanity filter : Activé
- Afficher en temps réel : Non (afficher après que tout le monde ait répondu)

### Notes de facilitation

- Insister sur l'anonymat pour libérer la parole
- Attendre que la majorité ait répondu avant d'afficher
- Lire quelques réponses à voix haute sans commenter négativement
- Répondre aux craintes principales :
  - "Je n'y connais rien" → "C'est justement le but, on part de zéro"
  - "C'est trop dur pour moi" → "On avance pas à pas, ensemble"
  - "Je vais m'ennuyer" → "On a prévu plein d'activités variées"
  - "Je vais être nulle" → "Il n'y a pas de notes, on est là pour découvrir"

### Craintes fréquentes (anticipées)

- Ne pas comprendre / être larguée
- S'ennuyer
- Devoir faire des maths
- Travailler seule
- Montrer son travail devant tout le monde
- Ne pas avoir d'idées créatives

## Debrief : comment exploiter les résultats

### Immédiatement (5 minutes)

1. **Humeur** : Commenter brièvement, montrer de l'empathie
2. **Nuage de mots** : Rebondir sur 2-3 mots intéressants, déconstruire les stéréotypes
3. **Attentes** : Montrer comment le programme répond aux attentes principales
4. **Craintes** : Rassurer de manière authentique, sans minimiser

### Phrase type pour conclure

> "Merci pour votre honnêteté ! Je garde ces réponses en tête pour la semaine. Mon objectif : que vendredi, vous repartiez avec [reprendre une attente populaire] et que les craintes qu'on a vues soient derrière vous."

### Utilisation ultérieure

- Reprendre les mêmes questions le vendredi pour mesurer l'évolution
- Adapter certaines activités si une crainte revient souvent
- Garder les captures d'écran pour le bilan de fin de semaine

## Guide de création dans Mentimeter

### Étapes de création

1. Connecte-toi sur [mentimeter.com](https://www.mentimeter.com)
2. Clique sur "New presentation"
3. Nomme-la : "MSCI 2026 - Prise de température Lundi"
4. Ajoute les 4 slides dans l'ordre

### Configuration générale

- **Thème** : Choisis un thème coloré et moderne
- **Pace** : "Presenter pace" (tu contrôles le défilement)
- **Langue** : Français

### Partage avec les étudiantes

1. Affiche le QR code en grand sur l'écran
2. Donne aussi l'URL courte : menti.com + code
3. Laisse 30 secondes pour que tout le monde se connecte
4. Vérifie le nombre de participantes connectées avant de commencer

### Conseil technique

- Teste le sondage avant le cours avec un collègue
- Prépare un backup en cas de problème Wi-Fi (voir version papier ci-dessous)

## Version papier (backup)

Si la connexion internet pose problème, voici une version simplifiée sur papier.

### Matériel nécessaire

- 70 petits papiers (post-it ou feuilles coupées)
- 4 grandes feuilles ou zones au tableau
- Feutres de couleur

### Adaptation des slides

#### Zone 1 : Humeur (vote à main levée)

Demande aux étudiantes de lever la main :
- "Qui est encore un peu endormie ?" (1-2)
- "Qui est dans un état neutre ?" (3)
- "Qui est motivée ?" (4-5)

#### Zone 2 : Nuage de mots

Distribue un post-it par personne. Consigne :
> "Écris un mot qui te vient quand tu penses à 'programmation'"

Collecte les post-it et affiche-les groupés au tableau.

#### Zone 3 : Attentes

Écris les 8 options au tableau. Chaque étudiante vient mettre une croix à côté de ses 3 choix (ou utilise des gommettes).

#### Zone 4 : Craintes

Distribue un post-it. Consigne :
> "Écris anonymement ce qui t'inquiète pour cette semaine"

Collecte les post-it, mélange-les, et lis-en quelques-uns à voix haute.
