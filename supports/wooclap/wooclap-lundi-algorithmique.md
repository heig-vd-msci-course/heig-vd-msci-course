## Notes pour l'équipe enseignante

### Avant le quiz

- [ ] Créer l'événement Wooclap sur app.wooclap.com
- [ ] Tester le quiz en mode prévisualisation
- [ ] Vérifier que le WiFi fonctionne pour 60-70 appareils
- [ ] Afficher le code d'accès sur grand écran

### Pendant le quiz

- **Encourager la participation** de l'ensemble du groupe
- **Commenter les résultats** après chaque question
- **Donner des indices** si une question est mal comprise
- **Valoriser les réponses** de tout le groupe

### Variante : Mode équipes

Si le WiFi ne supporte pas 70 connexions :
1. Un appareil par équipe de 4 personnes
2. Les équipes se consultent avant de répondre
3. Utiliser la fonctionnalité de mode compétition de Wooclap

### Questions bonus (si temps restant)

**Bonus 1 :** Combien fait 21 modulo 4 ?
- **Réponse :** 1 (car 21 = 5×4 + 1)

**Bonus 2 :** Si on commence à 21, qui a l'avantage ?
- **Réponse :** La personne qui commence (car 21 = 5×4 + 1)
